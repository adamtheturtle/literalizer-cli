# 2026.11.25 (2026-11-25)

## Changes

- Add support for Python 3.15.
- Expose nested call input with `--input-root-key` and collection formatting with `--collection-layout`, using the published Literalizer 2026.9.16 API.
- Run validation workflows for pull requests targeting feature branches so stacked changes receive the normal checks.
- Upgrade Literalizer to 2026.11.4.2, including the dependency fix for browser installations.
- Use Literalizer 2026.11.25.
  Roc now emits V1 syntax and uses positional calls.
  YAML supports named roots, Jsonnet supports local variable declarations, and PureScript supports custom wrapper module names with `--module-name` and qualified imports with `--qualified-import MODULE ALIAS`.
  Use `--program-name` for wrapped COBOL output and `--null-constructor-name` for Elm null values.
